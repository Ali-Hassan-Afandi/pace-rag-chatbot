# Mock Test, Quiz Mode, Reading Mode and Make Paper

Sources: https://www.pacegkacademy.com/PPSC-Paper-Instructions · /Make-Paper-Instructions · /QuizMode/allquizMode · /QuizMode/allMockTest · /QuizMode/allSubjects

## PPSC Mock Test (https://www.pacegkacademy.com/PPSC-Paper-Instructions)
A simulated PPSC-style paper that generates a result like PPSC. Students describe it as the site's unique feature.
**Paper instructions shown before the test starts:**
1. Read the instructions carefully before you start answering.
2. Only **90 minutes for 100 questions** is allowed.
3. Read the question paper carefully and check your answer.
4. Each question has four options. Click only one check button for the answer you think is correct.
5. Each question carries **1 mark** and **0.25 mark is deducted for each incorrect answer** (negative marking).
6. Use of a calculator is not allowed.
7. If a candidate has any observation on the paper, they may bring it to notice in the "Leave A Reply" section.
The user must tick a box confirming they have read the instructions.

## Make Paper (https://www.pacegkacademy.com/Make-Paper-Instructions)
Title: "Make Paper (Year Selection)". The user selects a **Quiz Starting Year** and **Quiz Ending Year** (options 2000 to 2025) and clicks Submit to generate a custom paper from past-paper questions within that range.

## Quiz Mode (https://www.pacegkacademy.com/QuizMode/allquizMode)
"Quiz Categories" with two variants:
- **Quiz (Highlighted Mode)** — https://www.pacegkacademy.com/QuizMode/quizModeHighlited
- **Quiz With DMC** (shows a result card/DMC at the end) — https://www.pacegkacademy.com/QuizMode/quizWithDMC
After a quiz a **result card** is generated and wrongly attempted questions can be reviewed.
